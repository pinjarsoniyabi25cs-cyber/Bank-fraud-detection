# Bank-fraud-detection

\## Business Problem

A mid-sized digital bank needs to detect fraudulent transactions in real-time while minimizing false positives that frustrate customers.



\## Target Metrics

\- Fraud recall: >80%

\- False positive rate: <5%

\- Inference latency: <100ms





\# Bank Fraud Detection System



An AI-powered fraud detection engine that flags suspicious banking transactions in real-time,

built to address a real industry challenge: catching fraud (under 0.2% of all transactions)

without overwhelming customers and analysts with false alarms.



\## Business Problem



A mid-sized digital bank processes over 500,000 transactions daily, with fraud making up

less than 1% of them. Outdated rule-based systems generate too many false positives while

missing sophisticated fraud patterns. This project builds an AI-powered engine that:



\- Flags suspicious transactions in real-time

\- Provides explainable decisions for regulatory compliance (PSD2, PCI DSS)

\- Balances catching fraud against minimizing false alerts



\## Results



| Metric | Target | Achieved |

|---|---|---|

| Fraud Recall | > 80% | \*\*86%\*\* |

| False Positive Rate | < 5% | \*\*0.07%\*\* |
